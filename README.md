# kushalgarg101.github.io

This is the personal site for Kushal Garg. It uses Jekyll and GitHub Pages.

## Local Preview

1) Install Ruby and Bundler
2) Install gems:
   bundle install
3) Serve locally:
   bundle exec jekyll serve
4) Open:
   http://127.0.0.1:4000

## Customize

- Update `_config.yml` (title/description)
- Edit `index.md`, `about.md`
- Add posts to `_posts/`
- Add research notes to `_notes/`
